# English-Grammar

English Grammar MCQ practice from foundational to advanced topics, organized by Level and Chapter.

## Folder and numbering rules

Keep all English Grammar quiz files in this repository. Use the established structure:

```text
Level-01/
  index.html
  Chapter-0001/
    index.html
    script.js
    style.css
    Images/
    Sounds/
  Chapter-0002/
    index.html
    script.js
    style.css
    Images/
    Sounds/
Level-02/
  Chapter-0101/
    index.html
    script.js
    style.css
    Images/
    Sounds/
```

Use project-wide sequential chapter numbering: Level-01 starts with Chapter-0001, and Level-02 continues with Chapter-0101. Keep each quiz's HTML, JavaScript, CSS, images, and sounds together. Do not reuse a chapter number for a different quiz.

## Publishing and website listing

- GitHub Pages: https://aliakbar1974.github.io/English-Grammar/
- Website grammar library: https://quizchallengebd.com/english-grammar-quizzes.html

The website library can discover published chapter folders from this repository. For a new chapter, add its folder and `index.html`, verify the GitHub Pages URL, then check the website library.

## Quiz quality checklist

- Confirm the correct-answer index matches the shuffled option order.
- Balance correct answers across A/B/C/D according to the brief.
- Include accurate explanations and example sentences.
- Test Learning Mode, Exam Mode, timer, sound assets, mobile layout, and return-to-Facebook controls.
- Keep chapter titles, page titles, and folder numbers consistent.
